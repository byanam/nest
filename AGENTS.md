# Workspace Rules

- **Browser Restriction**: Never open Google Chrome, launch browser subagents, or use interactive browser automation tools unless explicitly requested by the user. Do all debugging, inspection, testing, and implementation using CLI tools, code inspection, and direct file edits.
- **Git Commit**: Always commit the changes and push to GitHub after completing a task.

# Architecture & Structure

This is a high-performance, neo-brutalist creative studio landing page with pure vanilla web architecture:
- `index.html`: Main HTML entrypoint containing semantic markup and SVG vectors
- `public/styles.css`: Complete styling and design token definitions
- `public/script.js`: Interactive mechanics, Lenis smooth scrolling, and observers
- `public/lenis.min.js`: Bundled smooth scroll engine
- `public/`: High-resolution visual assets and favicon
